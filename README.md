# Automated Maize Leaf Disease Classification Using Transfer Learning and Image Augmentation

A deep learning–based computer vision project for classifying maize leaf images into **Healthy, Common Rust, Gray Leaf Spot, and Northern Leaf Blight** categories.

## Project Highlights

* Performed image-based exploratory data analysis and class distribution analysis
* Applied **class weighting** to address dataset imbalance
* Used image augmentation including flipping, rotation, zooming, height, and width transformations
* Built a transfer learning pipeline using **pretrained InceptionV3**
* Fine-tuned selected convolutional layers for maize disease classification
* Trained a four-class classifier using Nadam optimization and cross-entropy loss
* Achieved approximately **97.4% validation accuracy**
* Visualized training performance and model predictions on leaf images

## Tech Stack

`Python` • `TensorFlow` • `Keras` • `InceptionV3` • `NumPy` • `OpenCV` • `Matplotlib` • `Seaborn`

## Skills Demonstrated

**Computer Vision • Deep Learning • Transfer Learning • Image Classification • Data Augmentation • Class Imbalance Handling • CNN Fine-Tuning • Model Evaluation**

## Outcome

Developed an end-to-end deep learning pipeline capable of accurately distinguishing healthy maize leaves from three major leaf diseases using transfer learning and image-based classification.
